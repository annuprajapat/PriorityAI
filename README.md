# PriorityAI – AI-Based Complaint Priority System

# Overview

PriorityAI is a Machine Learning-based system that classifies complaints based on **priority** and **category** using NLP techniques.

# Features

* Predicts Priority (High, Medium, Low)
* Classifies Complaint Category
* Confidence Score
* Downloadable Report
* Interactive Streamlit UI

#  Technologies Used

* Python
* Scikit-learn
* Pandas
* Streamlit
* NLP (TF-IDF)

# How to Run

pip install pandas scikit-learn streamlit
python -m streamlit run app.py
